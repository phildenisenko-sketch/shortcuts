# Начните здесь

Image Shortcuts — это короткие команды для создания изображений.

## 1. Настройте нейросеть

Откройте [PROMPT.md](PROMPT.md), скопируйте текст и один раз вставьте его в ChatGPT, Claude, Gemini или другую нейросеть.

## 2. Выберите команду

- `/linkedin` — фото для работы
- `/lovestory` — романтическая фотосессия
- `/myclothes` — съёмка вашей одежды
- `/underwearcampaign` — съёмка нижнего белья
- `/paparazzi` — папарацци
- `/cinematic` — кадр как из фильма
- `/action` — движение и спорт
- `/anime` — аниме
- `/instagram` — фото для Instagram
- `/carousel` — Instagram-карусель
- `/avatar` — аватар
- `/travel` — путешествие
- `/product` — товар
- `/car` — автомобиль
- `/food` — еда
- `/website` — сайт

## 3. Напишите задачу обычными словами

```text
/myclothes

Сделай рекламную фотосессию этой футболки на модели.
```

Или:

```text
/paparazzi

Сделай меня на улице Нью-Йорка, будто меня случайно заметили фотографы.
```

Или:

```text
/food

Сделай профессиональную съёмку этого блюда для ресторана.
```

## 4. Можно уточнять результат

```text
/car

Сделай рекламную съёмку этой машины ночью.
Хочу мокрую улицу, отражения и несколько разных кадров.
```

Ваши дополнительные пожелания важнее стандартных настроек команды.

## Если не знаете команду

Просто напишите, что хотите получить. Нейросеть может сама подобрать подходящую команду.
