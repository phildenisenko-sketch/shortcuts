# 👋 Начните здесь

**Вам не нужно учиться писать сложные промпты.**

Image Shortcuts - это короткие команды, которые помогают быстро объяснить AI, **какую картинку вы хотите**.

## ⭐ Самые полезные команды

### 👤 Если это вы

- `/identity` - сохранить вашу внешность
- `/likeness` - сильнее сохранить сходство лица
- `/fullbody` - показать человека целиком
- `/sameperson` - сохранить одного человека в серии

### 📸 Если нужна фотография

- `/candid` - естественный непостановочный кадр
- `/paparazzi` - фото в стиле папарацци
- `/streetphoto` - уличная фотография
- `/photojournalism` - документальный стиль

### 👗 Если нужна одежда

- `/streetstyle` - street style
- `/fashioneditorial` - журнальная fashion-съемка
- `/lookbook` - лукбук
- `/outfitfocus` - акцент на одежде

### 💼 Для работы

- `/linkedin` - фото для LinkedIn
- `/executive` - деловой портрет
- `/founder` - фото основателя
- `/speaker` - фото спикера

### 🎬 Если хочется кино

- `/cinematic` - кинематографичный вид
- `/filmstill` - как кадр из фильма
- `/noir` - нуар
- `/scifi` - научная фантастика

### 📱 Для соцсетей

- `/story` - вертикальная Story
- `/carouselseries` - серия для карусели
- `/reelcover` - обложка Reels
- `/thumbnail` - обложка видео

### ✈️ Для путешествий

- `/travelphoto` - фото путешествия
- `/destination` - показать место как туристическую локацию
- `/hotel` - фото отеля

### 🏃 Для спорта

- `/action` - динамичный момент
- `/sportseditorial` - спортивная журнальная съемка
- `/motionblur` - показать движение с размытием

### 🎨 Для искусства

- `/anime` - аниме
- `/comicbook` - комикс
- `/watercolor` - акварель
- `/oilpainting` - масляная живопись

## Как написать запрос

Самый простой вариант:

```text
/identity /fullbody /streetstyle

Я иду по Нью-Йорку с кофе.
Сохрани мое лицо и мой аутфит.
```

Готово.

## Можно сочетать команды

```text
/identity /fullbody /paparazzi /35mm /daylight

Я иду по Бруклину с кофе.
```

## Можно менять команды

Shortcut не является жестким правилом.

```text
/paparazzi

Сделай кадр более случайным.
Фотограф стоит далеко.
Я не смотрю в камеру.
```

Ваши уточнения имеют приоритет.

## Можно создавать свои команды

Например:

```text
/mybrooklyn
```

Вы сами решаете, что означает ваш shortcut. Это удобно для любимого стиля, одежды, места или типа фотографии.
