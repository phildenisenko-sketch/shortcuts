# 📚 Все shortcuts

**Image Shortcuts Standard 1.0**

**291 команд в 36 категориях.**

Нажмите `Ctrl + F` (Windows) или `Cmd + F` (Mac), чтобы быстро найти команду.

Если не знаете, с чего начать, откройте **[START-HERE.md](START-HERE.md)**.

## Identity & Subject

| Команда | Что делает |
|---|---|
| `/identity` | Сохраняет личность и узнаваемые черты человека с reference. |
| `/likeness` | Сильнее приоритизирует сходство лица с reference. |
| `/bodymatch` | Сохраняет пропорции и телосложение. |
| `/ageaccurate` | Сохраняет соответствующий возрастной вид. |
| `/sameperson` | Сохраняет одного человека между кадрами. |
| `/identitylock` | Фиксирует лицо, прическу и пропорции. |

## Composition & Framing

| Команда | Что делает |
|---|---|
| `/closeup` | Крупный план лица. |
| `/headshot` | Портрет от плеч или груди вверх. |
| `/halfbody` | Кадр примерно от пояса или груди вверх. |
| `/fullbody` | Человек полностью в кадре. |
| `/wideshot` | Много окружающего пространства. |
| `/centered` | Объект находится в центре кадра. |
| `/ruleofthirds` | Композиция по правилу третей. |
| `/negativeSpace` | Оставляет свободное пространство вокруг объекта. |
| `/dynamic` | Более динамичная композиция. |

## Camera & Perspective

| Команда | Что делает |
|---|---|
| `/droneview` | Высокая воздушная перспектива с дрона. |
| `/aerial` | Воздушная съемка с большим контекстом. |
| `/birdseye` | Выраженный вид сверху. |
| `/topdown` | Камера почти прямо над объектом. |
| `/highangle` | Камера выше объекта и смотрит вниз. |
| `/lowangle` | Камера ниже объекта и смотрит вверх. |
| `/wormseye` | Очень низкий ракурс. |
| `/eyelevel` | Камера примерно на уровне глаз. |
| `/overtheshoulder` | Ракурс через плечо. |
| `/pov` | Вид от первого лица. |

## 📷 Полный каталог

Остальные shortcuts организованы по темам в исходном словаре. Ищите нужную команду через поиск страницы или открывайте соответствующий раздел в истории версий репозитория.

> Мы сознательно держим основной каталог простым: **команда + понятное объяснение**. Технические определения не должны мешать обычному пользователю.
