# ✨ Image Shortcuts

> **Простые команды для создания изображений с AI.**
>
> Не нужно быть prompt-инженером. Выберите короткую команду, добавьте обычную фразу - и получите нужный визуальный результат.

## Что это?

**Image Shortcuts** - открытый словарь коротких команд, которые помогают быстро объяснить AI, **какую картинку вы хотите получить**.

Например:

```
/paparazzi
Я иду по Нью-Йорку с кофе.
```

или:

```
/linkedin
Сделай профессиональное фото для моего профиля.
```

или:

```
/anime
Сделай меня персонажем аниме.
```

Команды можно сочетать:

```
/identity /fullbody /streetstyle /35mm

Я в Бруклине с бумажным стаканчиком кофе.
```

## Важно

**Это не встроенные команды ChatGPT.** Это понятные сокращения для промптов.

Их смысл берётся из словаря Image Shortcuts.

## 🚀 Как пользоваться

1. Откройте [список команд](SHORTCUTS.md) или нужную [категорию](categories/).
2. Скопируйте понравившуюся команду.
3. Напишите после неё обычным языком, что вы хотите.
4. При необходимости добавьте ещё одну команду.

### Пример

```
/fashioneditorial

Сделай меня в этом аутфите на улице Парижа.
Сохрани мое лицо.
```

### Несколько команд

```
/identity /fullbody /paparazzi /35mm /daylight

Я иду по Бруклину с кофе.
```

## 🎛️ Самое важное: команды можно менять под себя

Стандартное описание shortcut - **не жёсткое правило**.

Вы можете уточнить или изменить его прямо в запросе:

```
/paparazzi

Сделай кадр более случайным:
фотограф стоит далеко, снимает через улицу,
есть небольшой motion blur и я не смотрю в камеру.
```

Ваше уточнение имеет приоритет над стандартным описанием shortcut.

Вы можете даже полностью изменить смысл для одного запроса.

## 🧩 Можно создавать свои команды

Например:

```
/mybrooklyn
```

> Мой любимый стиль Brooklyn: естественный дневной свет, 35mm, street style, тёплые цвета, реалистичная кожа, полный рост.

## 🔢 Команды с параметрами

```
/series:6
/aspect:9x16
/aspect:4x5
```

## 👶 Подходит для новичков

Не нужно знать, что такое focal length, depth of field или semantic prompting.

Просто выбирайте понятные команды.
