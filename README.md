# Image Shortcuts

## Что это

Image Shortcuts помогает получать нужные изображения, не объясняя нейросети каждый раз десятки деталей.

Вместо длинного описания можно написать короткую команду, а после неё обычными словами сказать, что вы хотите получить.

Например:

```text
/myclothes

Сделай рекламную фотосессию этой футболки на мужчине.
```

Нейросеть сама должна продумать съёмку: как показать вещь, какие кадры сделать, как поставить человека, какой нужен свет и что важно сохранить.

---

# Как пользоваться

### Шаг 1. Один раз настройте нейросеть

Откройте [PROMPT.md](PROMPT.md), скопируйте текст и вставьте его в ChatGPT, Claude, Gemini или другую нейросеть.

После этого нейросеть будет понимать наши команды.

### Шаг 2. Выберите команду

Выберите то, что хотите сделать:

| Команда | Для чего |
|---|---|
| `/linkedin` | Фотосессия для LinkedIn и работы |
| `/lovestory` | Романтическая фотосессия пары |
| `/myclothes` | Фотосессия вашей одежды |
| `/underwearcampaign` | Рекламная съёмка нижнего белья |
| `/paparazzi` | Съёмка в стиле папарацци |
| `/cinematic` | Кадр как из фильма |
| `/action` | Динамичная съёмка в движении |
| `/anime` | Превращение фотографии в аниме |
| `/instagram` | Фотография для Instagram |
| `/carousel` | Серия фотографий для Instagram-карусели |
| `/avatar` | Аватар или фотография профиля |
| `/travel` | Фотосессия во время путешествия |
| `/product` | Рекламная съёмка товара |
| `/car` | Профессиональная съёмка автомобиля |
| `/food` | Профессиональная съёмка еды |
| `/website` | Изображение для сайта |

### Шаг 3. Напишите, что хотите

После команды не нужен специальный формат. Просто объясните задачу своими словами.

Например:

```text
/paparazzi

Сделай меня на улице Нью-Йорка, будто меня случайно заметили фотографы.
```

Или:

```text
/linkedin

Сделай мне новую фотографию для профиля. Хочу выглядеть уверенно, современно и естественно.
```

Или:

```text
/food

Сделай профессиональную фотосессию этого бургера для ресторана.
```

Или:

```text
/car

Сделай рекламную фотосессию этой машины ночью в Берлине.
```

Или:

```text
/carousel

Сделай карусель из этой фотографии для Instagram.
```

# Что делает команда

Команда — это не просто название жанра. Она должна экономить вам время.

Например, `/food` должна сама предусмотреть несколько полезных кадров: общий кадр блюда, вид сверху, крупный план ингредиентов и фактуры, детали и атмосферу стола. Свет, отражения, пар, соусы, крошки и другие детали должны выглядеть естественно.

`/car` должна сама предусмотреть разные ракурсы автомобиля, детали кузова и салона, движение, отражения, контакт шин с дорогой и рекламный свет.

`/carousel` должна сама позаботиться о размере, последовательности кадров, одинаковом человеке или товаре и разнообразии фотографий.

То же правило действует для всех остальных команд.

# Можно добавлять свои пожелания

Команда не запрещает вам уточнять результат.

```text
/myclothes

Сделай рекламную фотосессию этой футболки.
Хочу Нью-Йорк.
Модель должна идти по улице.
Сделай кадры дорогими, но не слишком постановочными.
```

Ваши дополнительные пожелания важнее стандартных настроек команды.

---

# Если не знаете, какую команду выбрать

Просто опишите задачу без команды.

Например:

> Сделай профессиональную фотосессию моей машины.

или:

> Сделай из этой фотографии красивую фотографию для профиля.

Нейросеть может сама понять, какая команда подходит.

# Главное

**Вы говорите, что хотите получить. Команда помогает нейросети самой продумать детали.**

Не нужно писать длинные промты, если нужная команда уже существует.
