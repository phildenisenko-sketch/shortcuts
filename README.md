# Image Shortcuts

## Что это

Image Shortcuts — это короткие команды, которые помогают нейросети самой продумать детали создания изображения.

У пользователя есть два способа работы:

1. написать команду, если вы её знаете;
2. просто описать желаемый результат своими словами, если команду не помните.

Во втором случае нейросеть должна сама понять смысл запроса и применить подходящую команду, если для такой задачи она есть.

---

## Как пользоваться

### Шаг 1. Один раз настройте нейросеть

Откройте [PROMPT.md](PROMPT.md), скопируйте текст и один раз вставьте его в ChatGPT, Claude, Gemini или другую нейросеть.

После этого нейросеть будет понимать команды и сможет подбирать их по смыслу.

### Шаг 2. Дальше просто пишите, что вам нужно

**Если знаете команду**, напишите её:

```text
/paparazzi
```

```text
/food
```

```text
/car
```

**Если не знаете или не помните команду**, ничего страшного. Просто опишите задачу своими словами:

```text
Сделай меня на улице Нью-Йорка, будто меня случайно заметили фотографы.
```

```text
Сделай профессиональную съёмку этого блюда для ресторана.
```

```text
Сделай рекламную фотосессию этой машины ночью в Берлине.
```

Нейросеть должна сама определить подходящую команду и применить её подробные настройки.

### Шаг 3. При необходимости уточните результат

После этого можно обычными словами добавить любые пожелания: место, одежду, настроение, время суток, фон и всё остальное, что для вас важно.

Ваши пожелания важнее стандартных настроек команды.

## Какие команды есть

| Команда | Для чего |
|---|---|
| `/linkedin` | Фото для работы |
| `/lovestory` | Фотосессия пары |
| `/myclothes` | Съёмка вашей одежды |
| `/underwearcampaign` | Съёмка нижнего белья |
| `/paparazzi` | Съёмка папарацци |
| `/cinematic` | Кадр как из фильма |
| `/action` | Динамичная съёмка |
| `/anime` | Аниме-подача |
| `/instagram` | Фото для Instagram |
| `/carousel` | Серия фото для Instagram |
| `/avatar` | Фото профиля или аватар |
| `/travel` | Фотосессия в путешествии |
| `/product` | Съёмка товара |
| `/car` | Съёмка автомобиля |
| `/food` | Съёмка еды |
| `/website` | Изображение для сайта |

## Почему это работает

Команда — не просто название жанра. Она нужна для того, чтобы не объяснять нейросети каждый раз десятки деталей.

Например, `/food` должна сама продумать полезные кадры блюда, свет, фактуру, пар, соусы, крошки и детали стола.

`/car` должна сама продумать разные ракурсы автомобиля, детали кузова и салона, движение, отражения, контакт шин с дорогой и рекламный свет.

`/carousel` должна сама позаботиться о размере, последовательности кадров, одинаковом человеке или товаре и разнообразии фотографий.

То же правило действует для остальных команд.
