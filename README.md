## Как это работает

Напишите:

```text
/paparazzi
Я иду по Нью-Йорку с кофе.
```

Или:

```text
/linkedin
Сделай профессиональное фото для моего профиля.
```

Можно сочетать команды:

```text
/identity /fullbody /streetstyle /35mm

Я в Бруклине с кофе.
```

## 🎛️ Команды можно менять

Shortcut задаёт направление, но **не ограничивает вас**.

Например:

```text
/paparazzi

Сделай кадр более случайным. Фотограф стоит далеко,
я не смотрю в камеру и есть небольшое размытие движения.
```

Ваши уточнения важнее стандартного значения команды.

## 🧩 Можно создавать свои команды

Например:

```text
/mybrooklyn
```

Вы сами решаете, что означает ваш shortcut. Это удобно для любимого стиля, одежды, места, типа фотографии или повторяющегося формата.

## 🔢 Можно использовать параметры

```text
/series:6
/aspect:9x16
/aspect:4x5
```

## Важно

**Image Shortcuts не являются встроенными командами ChatGPT или другой AI-платформы.** Это открытый словарь сокращений, который можно использовать в своих промптах, GPT, проектах и AI-инструментах.
