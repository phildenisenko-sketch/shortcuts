## Как пользоваться

После установки просто пишите:

```text
/identity /fullbody /streetstyle /35mm

Сделай меня на улице в Нью-Йорке с кофе.
Сохрани моё лицо и одежду.
```

Можно использовать одну команду или несколько сразу.

## ⭐ Команды можно менять

Команда задаёт направление, но не ограничивает вас.

```text
/paparazzi

Сделай кадр более случайным.
Фотограф стоит далеко, я не смотрю в камеру.
```

Ваши дополнительные пожелания важнее стандартного значения команды.

## 🧩 Можно создавать свои команды

Например:

```text
/mybrooklyn
```

Вы сами решаете, что означает ваша команда. Это удобно для любимого стиля, одежды, места или повторяющегося типа фотографии.

## 🔢 Можно использовать параметры

```text
/series:6
/aspect:9x16
/aspect:4x5
```
