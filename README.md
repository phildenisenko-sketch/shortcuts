## Как это работает

Напишите:

```text
/paparazzi
Я иду по Нью-Йорку с кофе.
```

Или:

```text
/linkedin
Сделай профессиональное фото для моего профиля.
```

Можно сочетать команды:

```text
/identity /fullbody /streetstyle /35mm

Я в Бруклине с кофе.
```

## ⭐ Команды можно менять

Команда задаёт направление, но **не ограничивает вас**.

```text
/paparazzi

Сделай кадр более случайным.
Фотограф стоит далеко, я не смотрю в камеру,
без вспышки.
```

Ваши уточнения важнее стандартного поведения команды.

## 👕 Одежда и нижнее бельё

Для брендов есть отдельный набор команд для коммерческой съёмки:

- на взрослых моделях;
- на улице;
- в интерьере;
- в магазине;
- на вешалке;
- на рейле;
- на полке;
- в формате lookbook;
- в формате каталога и интернет-магазина.

Начните с **[категории одежды](categories/08-clothing.md)**.

Например:

```text
/underwearcampaign /adultmodel /interiorcampaign /softlight

Сделай коммерческую фотосессию этой новой коллекции белья.
Покажи посадку, ткань и дизайн товара.
```

## 🧩 Можно создавать свои команды

Например:

```text
/mybrooklyn
```

Вы сами решаете, что означает ваша команда. Это удобно для любимого стиля, одежды, места или повторяющегося типа фотографии.

## 🔢 Можно использовать параметры

```text
/series:6
/aspect:9x16
/aspect:4x5
```
