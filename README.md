# Image Shortcuts

Image Shortcuts помогает получать профессиональные изображения без длинных промтов.

## Как это работает

Есть два способа пользоваться системой.

### Если вы знаете шорткат

Просто напишите команду:

```text
/paparazzi
```

Если в разговоре уже есть фотография или описание задачи, система использует их вместе с рецептом этого шортката.

### Если вы не знаете шорткат

Ничего запоминать не нужно. Просто напишите своими словами, что хотите получить:

```text
Сделай меня на улице Нью-Йорка так, будто меня случайно заметили фотографы.
```

Если для такой задачи есть подходящий шорткат, система сама найдёт его рецепт и применит его.

То есть вам не нужно писать `/paparazzi`.

Точно так же:

```text
Сделай профессиональную фотосессию этой машины ночью в Берлине.
```

система может сама использовать рецепт `/car`.

И:

```text
Сделай профессиональную фотосессию этого бургера для ресторана.
```

система может сама использовать рецепт `/food`.

## Главное правило

**Либо напишите шорткат, либо просто скажите, что хотите получить.**

Не нужно писать шорткат и потом повторять длинный промт.

Шорткат нужен только для того, чтобы быстро выбрать готовый подробный рецепт. Если вы не помните его название, система должна понять задачу по смыслу.

## Какие шорткаты есть

- `/linkedin` — фотография для работы
- `/lovestory` — фотосессия пары
- `/myclothes` — съёмка вашей одежды
- `/underwearcampaign` — рекламная съёмка нижнего белья
- `/paparazzi` — случайный кадр в стиле папарацци
- `/cinematic` — сцена как в кино
- `/action` — фотография в движении
- `/anime` — аниме-подача
- `/instagram` — фотография для Instagram
- `/carousel` — серия связанных фотографий
- `/avatar` — аватар или фотография профиля
- `/travel` — фотосессия во время путешествия
- `/product` — рекламная съёмка товара
- `/car` — автомобильная фотосессия
- `/food` — профессиональная съёмка еды
- `/website` — изображение для сайта

## Почему шорткаты полезны

Шорткат — это не просто слово вроде «еда» или «машина».

У каждого шортката есть подробный рецепт. Например, `/food` учитывает разные полезные ракурсы, фактуру блюда, свет, пар, соусы, влагу, крошки, посуду и окружение.

`/car` учитывает форму кузова, отражения, колёса, контакт шин с дорогой, движение, салон и разные рекламные ракурсы.

Поэтому вам не нужно каждый раз объяснять всё это самостоятельно.
