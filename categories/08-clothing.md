# 👕 Одежда, бельё и съёмка товара

Эта категория для брендов одежды, белья и магазинов.

Здесь можно быстро собрать съёмку товара **на модели, на улице, в интерьере, в магазине, на вешалке, на рейле или на полке**.

Все команды про бельё здесь предполагают **взрослых моделей** и обычную коммерческую подачу товара.

## Команды

| Команда | Что она делает |
|---|---|
| `/adultmodel` | Использует взрослых моделей для коммерческой съёмки одежды или белья. |
| `/productphoto` | Чистая коммерческая фотография товара. |
| `/onmodel` | Показывает одежду на модели. |
| `/lingeriecampaign` | Коммерческая съёмка нижнего белья на взрослых моделях. |
| `/underwearcampaign` | Коммерческая съёмка нижнего белья на взрослых моделях. |
| `/lingeriemodel` | Показывает бельё на взрослой модели естественно и как товар. |
| `/underwearmodel` | Показывает бельё на взрослой модели естественно и как товар. |
| `/lookbook` | Делает серию фотографий одежды на модели. |
| `/streetwear` | Показывает одежду на улице. |
| `/streetstylemodel` | Делает живой street-style образ на модели. |
| `/outdoorcampaign` | Съёмка одежды или белья на улице или природе. |
| `/interiorcampaign` | Съёмка одежды или белья в красивом интерьере. |
| `/storecampaign` | Съёмка товара внутри магазина. |
| `/storeinterior` | Показывает товар внутри магазина или шоурума. |
| `/hanger` | Показывает одежду на вешалке. |
| `/rack` | Показывает одежду на рейле или стойке. |
| `/shelfdisplay` | Показывает товар на полке магазина. |
| `/retaildisplay` | Делает аккуратную выкладку товара в магазине. |
| `/folded` | Показывает аккуратно сложенную одежду. |
| `/flatlay` | Раскладывает товар для съёмки сверху. |
| `/ghostmannequin` | Показывает одежду без видимого тела модели. |
| `/catalog` | Делает чистую каталожную фотографию. |
| `/ecommerce` | Делает фотографию для интернет-магазина. |
| `/texture` | Подчёркивает фактуру материала. |
| `/fabricdetail` | Показывает ткань, швы и детали крупным планом. |
| `/garmentfront` | Показывает одежду спереди целиком. |
| `/garmentback` | Показывает одежду сзади целиком. |
| `/detailshot` | Крупный план детали товара. |
| `/packshot` | Чистый изолированный кадр товара. |
| `/luxuryproduct` | Премиальная коммерческая подача товара. |

## Готовые примеры

### 🩲 Нижнее бельё на модели

```text
/underwearcampaign /adultmodel /interiorcampaign /softlight

Сделай коммерческую фотосессию этой новой коллекции белья.
Взрослая модель, современный светлый интерьер,
естественная поза. Покажи посадку, ткань и дизайн товара.
```

### 🏙️ Одежда на улице

```text
/streetwear /streetstylemodel /fullbody /35mm /daylight

Сделай серию фотографий этой куртки на модели
на улицах Берлина. Покажи одежду целиком.
```

### 🏪 Одежда в магазине

```text
/storecampaign /storeinterior /retaildisplay

Покажи эту коллекцию в современном магазине:
часть вещей на рейле, часть на полках,
несколько товаров на модели.
```

### 🧥 Вещь на вешалке

```text
/hanger /catalog /daylight

Покажи это платье на красивой вешалке,
чтобы были хорошо видны форма, цвет и материал.
```

### 📦 Карточка товара

```text
/productphoto /ecommerce /front

Покажи этот товар чисто и аккуратно,
чтобы хорошо были видны форма, цвет и детали.
```

**Совет:** команды можно сочетать. Если нужно что-то изменить, просто напишите это обычными словами.
