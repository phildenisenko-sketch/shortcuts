# 👕 Одежда, бельё и съёмка товара

Эта категория для **брендов одежды, белья, магазинов и каталогов**.

Здесь можно собрать коммерческую фотосессию товара **на взрослых моделях, на улице, в интерьере, в магазине, на вешалке, на рейле или на полке**.

### Важно

Команды для белья описывают **обычную fashion / product photography**. Главная задача такой съёмки - показать сам товар: его дизайн, цвет, материал, крой, посадку и детали.

Это не команда для эротической или сексуальной сцены. Используйте обычную рекламную, каталожную, editorial или lifestyle-подачу.

## Команды

| `/productphoto` | Чистая коммерческая фотография товара. |
| `/onmodel` | Показывает одежду на модели. |
| `/lingeriecampaign` | Коммерческая fashion-съёмка коллекции белья на взрослых моделях с акцентом на товар. |
| `/underwearcampaign` | Коммерческая fashion-съёмка коллекции белья на взрослых моделях с акцентом на товар. |
| `/lingeriemodel` | Показывает бельё на взрослой модели в обычной каталожной или fashion-подаче. |
| `/underwearmodel` | Показывает бельё на взрослой модели в обычной каталожной или fashion-подаче. |
| `/lookbook` | Делает серию фотографий одежды на модели. |
| `/streetwear` | Показывает одежду на улице. |
| `/streetstylemodel` | Делает живой street-style образ на модели. |
| `/outdoorcampaign` | Съёмка одежды или белья на улице или природе. |
| `/interiorcampaign` | Съёмка одежды или белья в красивом интерьере. |
| `/storecampaign` | Съёмка товара внутри магазина. |
| `/storeinterior` | Показывает товар внутри магазина или шоурума. |
| `/hanger` | Показывает одежду на вешалке. |
| `/rack` | Показывает одежду на рейле или стойке. |

| `/flatlay` | Раскладывает товар для съёмки сверху. |

| `/packshot` | Чистый изолированный кадр товара. |
| `/luxuryproduct` | Премиальная коммерческая подача товара. |

## Готовые примеры

### 🩲 Коммерческая съёмка белья

```text
/lingeriecampaign /adultmodel /interiorcampaign /softlight

Сделай коммерческую fashion-съёмку этой новой коллекции белья.
Взрослая модель, современный светлый интерьер,
естественная поза и обычная рекламная подача.
Главный акцент - дизайн, посадка, ткань, цвет и детали товара.
```

### 🏙️ Бельё в lifestyle-сцене

```text
/underwearcampaign /adultmodel /lifestyle /natural

Сделай lifestyle-фотографию новой коллекции белья
в светлой современной квартире.
Взрослая модель, естественная повседневная сцена,
акцент на продукте и его дизайне.
```

### 🏙️ Одежда на улице

```text
/streetwear /streetstylemodel /fullbody /35mm /daylight

Сделай серию фотографий этой куртки на модели
на улицах Берлина. Покажи одежду целиком.
```

### 🏪 Одежда в магазине

```text
/storecampaign /storeinterior /retaildisplay

Покажи эту коллекцию в современном магазине:
часть вещей на рейле, часть на полках,
несколько товаров на модели.
```

### 🧥 Вещь на вешалке

```text
/hanger /catalog /daylight

Покажи это платье на красивой вешалке,
чтобы были хорошо видны форма, цвет и материал.
```

### 📦 Карточка товара

```text
/productphoto /ecommerce /front

Покажи этот товар чисто и аккуратно,
чтобы хорошо были видны форма, цвет и детали.
```

**Совет:** команды можно сочетать. Если нужно что-то изменить, просто напишите это обычными словами.
