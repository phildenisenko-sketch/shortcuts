# 🎬 Visual School Reference Lineage

Visual Schools are **original creative directions**, not instructions to copy a brand campaign, film frame, photographer, director or living artist.

References below are used to identify the visual decisions behind each school. The engine should extract principles, not reproduce a specific work.

## Why references are separated from the recipes

A reference name is useful for humans because it quickly communicates a territory. It is not reliable enough as the actual generation instruction.

For example, instead of telling an image model:

```text
make it like Jacquemus
```

Image Shortcuts should translate the reference into a reusable direction such as:

```text
vast controlled landscape, graphic architecture, deliberate scale contrast,
one memorable surreal element, restrained palette, clear silhouette,
precise negative space, editorial staging
```

This makes the Visual School portable across portraits, fashion, travel, products, cars, LinkedIn and other domains.

## Current reference examples

The library's reference research includes documented campaign characteristics such as Jacquemus's open landscapes and distilled surrealism, Zara's restrained editorial advertising language, Bottega Veneta's recent multi-photographer grain/flash/documentary approach, and Louis Vuitton's travel campaigns built around landscape, architecture and discovery.
