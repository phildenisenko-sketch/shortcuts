# 📐 Output Profiles

Visual DNA decides **how the image feels**. Output Profiles decide **what the deliverable needs to be**.

The user should not have to repeat obvious technical requirements every time.

## Instagram Post

Default:
- portrait 4:5;
- strong subject readability;
- composition survives mobile crop;
- enough breathing room for optional UI/text;
- polished single-image composition.

## Instagram Carousel

Default:
- portrait 4:5;
- 6-image coherent series unless the user requests another count;
- one Visual DNA across the whole series;
- consistent identity, garment, product, lighting logic and color treatment;
- variation across wide, medium, close and detail frames;
- each frame works independently and also contributes to a sequence;
- avoid repeating the same pose and crop.

## LinkedIn Portrait

Default:
- vertical portrait framing suitable for profile use;
- face remains clearly readable at small size;
- professional but not generic corporate staging;
- preserve natural skin and identity;
- Visual DNA may add editorial character while keeping the image credible for professional use.

## Avatar

Default:
- square composition;
- face or defining subject occupies a strong readable area;
- clean silhouette;
- minimal background competition;
- preserve identity above all else.

## Dating Profile

Default:
- vertical portrait;
- natural full-body or three-quarter option when useful;
- environment communicates personality;
- candid body language rather than formal headshot posture;
- face remains recognizable.

## Fashion Campaign

Default:
- editorial composition;
- product/garment remains legible;
- allow multiple visual distances;
- use the selected Visual DNA consistently;
- prioritize silhouette, material, styling and narrative.

## Product / E-commerce

Default:
- product identity and geometry are protected;
- clean readable presentation;
- no unnecessary props unless requested;
- Visual DNA may influence environment and lighting but must not obscure product information.

## Cinematic Still

Default:
- widescreen cinematic composition unless another output is requested;
- strong foreground/midground/background separation;
- motivated light;
- frame should imply a story rather than look like a posed photograph.

## Presentation / Website Hero

Default:
- horizontal composition;
- strong focal area;
- intentional copy space when appropriate;
- subject and visual hierarchy remain clear after cropping.

## General rule

If the user explicitly gives dimensions, aspect ratio, number of images or framing, those instructions override the profile.

If the user does not specify them, use the relevant Output Profile instead of asking unnecessary questions.

Output Profiles should solve **delivery problems**. Visual DNA should solve **creative problems**.
