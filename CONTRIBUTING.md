# Как предложить новую команду

Спасибо за вклад!

## Простые правила

1. Название должно быть коротким и понятным.
2. Объясните простыми словами, что делает команда.
3. Добавьте пример.
4. Укажите, в какой раздел её лучше добавить.
5. Не называйте команду официальной функцией ChatGPT, Gemini, Midjourney или другой платформы.
6. Не меняйте молча смысл уже существующей команды.

## Пример

```text
Команда: /myexample

Что делает:
Делает мягкий утренний свет и спокойную атмосферу.

Пример:
/myexample
Сделай фотографию завтрака у окна.
```

## Если команда уже существует

Не создавайте новую команду только ради небольшого изменения. Пользователь может просто уточнить желаемый результат обычными словами.
