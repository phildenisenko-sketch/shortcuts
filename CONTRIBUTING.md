# Как предложить новую команду

1. Название должно быть коротким и понятным.
2. Добавьте простое описание на русском.
3. Добавьте semantic definition на английском.
4. Укажите категорию.
5. Добавьте пример.
6. Не называйте shortcut официальной функцией конкретной AI-платформы.
7. Не меняйте молча значение существующего shortcut.

Пользовательские изменения default-поведения - нормальная часть ISS.
